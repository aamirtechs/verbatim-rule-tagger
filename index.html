How it works

  • CSV in: an id column plus a text column of survey verbatims or ticket comments.
  • Rule editor: label = any / all / not keywords, or a regex rule with clear error reporting.
  • Multi-label matching in rule order, with hit counts and percentages per label.
  • Co-occurrence table shows which labels tend to appear together.
  • A deterministic seeded audit sample lets a second reviewer check the same records, and everything exports as a tagged CSV.
